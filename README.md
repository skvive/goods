# SwagForge / Goods

Official domain: https://goods.lexid.site

B2B customized printing & corporate swag showcase. Static HTML/CSS/JS hosted on Vercel.

Features: homepage, live 3D preview with Three.js CDN/fallback, welcome kit price builder, quantity-tier quote calculator with printable draft, SEO insights, sitemap, robots and RSS.

All products/prices are illustrative. No production payments, invoices, user database, vendor ordering or authenticated Blogger publishing are implemented.

Deploy: Vercel project connected to skvive/goods main, no build command required.
